# 제품 정의 (v0)

## 한 문장

보내지 못한 말을 남겨두는 벽. 어떤 편지는 누구나 읽을 수 있고, 어떤 편지는 그 말을 알아볼 사람만 열 수 있다.

## 문제

기존 메시지는 보내는 순간 도달한다. 그래서 거절·민망함·관계 악화가 두려운 사람은 아무것도 보내지 못하고 감정을 혼자 보관한다. 반대편 사람은 자신을 향한 말이 존재하는지조차 모른다.

## 사용자 세 유형

- **작성자** — 전하지 못한 말이 있는 사람. 쓰는 것 자체로 일부 해소된다.
- **발견자** — "혹시 나에게?"로 들어와 단서를 읽고 열어보는 사람.
- **관찰자** — 남의 감정을 읽으러 오는 사람. 수가 가장 많고, 나중에 작성자가 된다.

세 유형이 모두 있어야 돌아간다. 관찰자 없이는 트래픽이 없고, 발견자 없이는 이야기가 없고, 작성자 없이는 콘텐츠가 없다.

## 편지 3모드

| | A. 공개 비잠금 | B. 공개 잠금 | C. 비공개 지정 |
|---|---|---|---|
| 피드 노출 | 카드 + 본문 | 카드 + 단서 (본문 가림) | 없음 |
| 열람 조건 | 없음 | 키 일치 | 지정 수신자 본인 |
| 작성자 계정 | 불필요 | 불필요 | **필수** |
| 개인정보 수집 | 없음 | 없음 | 식별자 |
| v0 포함 | ✅ | ✅ | ❌ (스키마만 예약) |

C는 제거가 아니라 연기다. 근거는 [결정 로그 D-003](./00-decisions.md).

## 핵심 루프

```
쓴다 (A/B, 무계정)
  → 카드가 생긴다
  → 단톡방·SNS에 공유된다
  → 새 방문자가 카드를 본다
  → B면 열어본다 / A면 읽는다
  → "나도 있다" → 쓴다
```

이 루프에서 **공유가 유일한 배달 수단**이다. 비사용자에게 어떤 알림도 발송하지 않기로 했기 때문이다([D-006](./00-decisions.md)). 따라서 카드 디자인은 장식이 아니라 유통 인프라다.

재방문 훅은 하나뿐이다: **"내가 쓴 편지가 열렸는가."** 이건 실제로 발생한 사건이라 알려도 정직하다. 다만 문구는 "상대가 읽었다"가 아니라 "누군가 열었다"다([D-007](./00-decisions.md)).

## 이 제품이 아닌 것

- 익명 채팅 / 익명 DM
- 사람 찾기 서비스
- 소개팅·재회 중개
- 폭로·저격 게시판
- 상담이나 치료

새 기능 요청이 오면 이 목록에 걸리는지부터 본다.

## 제품 원칙

1. 상대의 통제권이 작성자의 전달 욕구보다 우선한다.
2. 존재하지 않는 신호를 만들지 않는다.
3. 비사용자에게 먼저 연락하지 않는다.
4. 공개된 콘텐츠에서 실제 인물을 특정할 수 없어야 한다.
5. 돈을 내야 열 수 있게 만들지 않는다.
6. 트래픽과 신고율을 같은 화면에서 본다.

## 북극성 지표

**주간 "본인에게 온 편지였다"고 응답한 열람 수.**

단순 열람 수를 쓰지 않는 이유: 잠긴 편지는 제3자도 열 수 있고, 열림 자체로는 의도한 사람에게 닿았는지 알 수 없다. 열람 직후 한 번만 묻는다 — *"이 편지, 당신에게 온 것 같나요?"* 자기 응답이라 부정확하지만, 유일하게 정직한 측정이다.

함께 보는 방어 지표:

- **신고율** — 게시 편지 대비
- **24시간 내 삭제율** — 작성 직후 후회의 크기 ([계측 §6](./06-analytics.md) #7). 관리 링크 분실 요청은 이벤트가 없어 지표가 아니라 운영 큐로 본다
- **인터스티셜 회귀율** — 경고를 보고 `고칠게요`를 누른 비율. 작성 시점 개입이 실제로 작동하는지 직접 측정한다
- **자동 비공개 미판정 적체** — 운영 역량의 선행 지표

> 초안에 있던 "열람 후 불쾌 응답률"과 "동일 대상 반복 작성 시도율"은 뺐다. 전자는 질문을 하나 더 붙여야 하는데 마찰 대비 이득이 없어 신고율로 대체하고, 후자는 v0에 수신자 식별자가 없어 **측정 자체가 불가능하다**. 근거: [데이터 모델 §5 발견 4·5](./04-data-model.md).

## v0 범위

**포함**
- 무계정 편지 작성 (모드 A / B 선택)
- B 모드: 단서 + 키 설정, 열람 시도 (시도 횟수 제한)
- 공개 피드 (관계·감정 필터, 고정형 반응)
- 공유 카드 (OG 이미지)
- 신고 버튼, 작성자 본인 삭제
- 운영자 검토 큐 + 전체 비공개 킬 스위치
- 알림용 이메일 선택 수집
- 분석 이벤트

**제외**
- 모드 C 전체 (편지함, 본인 소유증명, 사전 차단)
- 자유 댓글, 대댓글
- 계정·프로필·팔로우
- 사진·영상·음성
- 답장, 재연결
- 결제
- 네이티브 앱
